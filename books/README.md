## 🛠 Генерація / Оновлення книги

Для перекомпіляції книги з актуальних нотаток виконайте через Deno:

```bash
deno run --allow-read --allow-write tools/build_book.ts
```

Параметри CLI (опціонально):
* `--input=<path>` — директорія вихідних нотаток (за замовчуванням: `./quotes/Monday/chat-0001`)
* `--output=<path>` — шлях до цільового `.md` файлу (за замовчуванням: `./books/chtyvo_dlya_vashoho_ai.md`)
* `--title="<title>"` — назва книги
* `--author="<author>"` — автори видання
